# Security policy

TANNO never asks for a private key, seed phrase, or wallet recovery phrase. Wallet connection should disclose only a public account; any token burn must be explicitly approved in the wallet. Do not enter secrets into `config/project.json` or a public issue.

To report a vulnerability, use GitHub's **Report a vulnerability** / private security advisory for this repository if available. If private advisories are unavailable, open a minimal public issue that does **not** include exploit details, credentials, or sensitive data, and request a private channel. There is no published security mailbox to invent here.

This repository has not been audited. Current mint configuration is empty and production burn is not active. A wallet-signed transaction path in source code is not a security certification. Maintainers should reproduce reports, patch, test, and disclose after affected deployments are corrected.
